🎬 Netflix Content Analysis with Python

This project explores patterns and trends in Netflix's streaming catalog using Python. It showcases skills in data cleaning, exploratory data analysis (EDA), and data visualization to derive insights from real-world datasets.

📌 Project Objective
The goal of this project is to analyze Netflix’s library to understand:
- The distribution of movies and TV shows
- Trends in content growth over the years
- Popular countries and genres
- Top contributing directors

📁 Dataset Overview

- Source: [Netflix Movies and TV Shows - Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- Size: ~8,800 titles
- Features: Title, Type (Movie/TV Show), Country, Date Added, Genre, Duration, etc.
- Period: Data includes entries from 1925 to 2021
- 
🧰 Tools & Technologies
- Python
- Google Colab
- Pandas– data wrangling, feature engineering
- Matplotlib– basic visualizations
- Seaborn– enhanced plotting for storytelling

📊 Key Insights
 📺 Content Type Distribution
- Movies make up the majority of Netflix's catalog.
- TV shows are growing but still fewer in number.

 📈 Library Growth Over Time
- Rapid growth between 2016–2020 reflects Netflix's global expansion and original content strategy.

🌍 Top Producing Countries
- The United States leads in content count.
- India, the UK, and Canada are also major contributor
 4. Most Popular Genres
- Documentaries and dramas dominate the content library.
  
 🎬 Top Directors
- Certain directors appear frequently, showing strong partnerships with Netflix.
Skills Demonstrate
